# ReAlgo email system

Набор брендированных транзакционных и продуктовых писем ReAlgo. Шаблоны
собраны на табличной вёрстке, имеют скрытый preheader, мобильную адаптацию и
отдельную plain-text версию.

## Состав

| Файл | Сценарий | Рекомендуемый триггер |
|---|---|---|
| `welcome` | Успешная регистрация | Сразу после создания аккаунта |
| `interview-soon` | Скорое собеседование | За 7, 3 и 1 день, не чаще одного письма в сутки |
| `password-reset` | Запрос смены пароля | После подтверждённого запроса пользователя |
| `password-changed` | Пароль изменён | Сразу после успешной смены |
| `support-reply` | Ответ поддержки | При ответе агента или закрытии обращения |
| `review-reminder` | Карточки к повторению | В выбранное пользователем время, только при непустой очереди |
| `weekly-digest` | Недельный прогресс | Один раз в неделю при включённом дайджесте |

## Сборка и предпросмотр

```sh
node design/email-templates/render.mjs
open design/email-templates/dist/index.html
```

- `dist/templates/*.html` — версии с Go-style переменными `{{.Name}}`;
- `dist/preview/*.html` — заполненные примерами версии для дизайн-ревью;
- `dist/text/*.txt` — обязательные текстовые альтернативы;
- `dist/index.html` — каталог с предпросмотром всех писем.

Для реальной отправки HTML следует компилировать через `html/template`, чтобы
значения экранировались автоматически. URL действий должны быть абсолютными,
подписанными, одноразовыми и ограниченными по времени. Секреты и токены нельзя
писать в логи.

## Общие правила тона

- Говорим коротко и спокойно, без маркетингового давления.
- Один главный сценарий — одна основная кнопка.
- Объясняем не функцию, а следующий понятный шаг пользователя.
- В security-письмах не используем шутки, игровые формулировки и лишние CTA.
- Не обещаем результат собеседования; показываем прогресс и управляемое действие.

## Следующие шаблоны

1. **Подтверждение email** — обязательный шаг перед включением чувствительных
   уведомлений и восстановлением доступа.
2. **Новый вход в аккаунт** — устройство, время, примерный регион и кнопка
   завершения всех сессий.
3. **Расширение подключено** — короткий тестовый сценарий до первого Accepted.
4. **Импорт истории завершён** — сколько задач распознано и что делать с
   неразмеченными.
5. **Интервью завершилось** — мягкий запрос результата и обновление следующей
   цели без давления.
6. **Возвращение после паузы** — не «мы скучаем», а безопасный план на 5 минут
   без восстановления огромного streak.
7. **Экспорт данных готов** — защищённая ссылка со сроком действия.
8. **Удаление аккаунта** — запрос, период отмены и финальное подтверждение.
9. **Инцидент сервиса** — признание проблемы, текущий статус и итоговый postmortem.
10. **Командное приглашение** — кто пригласил, в какую группу и какие данные
    станут видны ментору.
