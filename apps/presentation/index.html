03:40–04:05

Слева два клиента: кабинет на Next.js и расширение на Plasmo. Оба приходят по HTTPS через Caddy в модульный Go API. API хранит постоянное состояние в PostgreSQL, а Redis использует для кэша, блокировок и лимитов. FSRS внутри API рассчитывает повторения. Отдельный AI Orchestrator собирает условие, текущий код и паттерны, вызывает Gemini 2.5 Flash через provider adapter и строго валидирует JSON. Подсказки возвращаются в расширение потоком SSE, а три сгенерированные карточки дедуплицируются и сохраняются в PostgreSQL.
