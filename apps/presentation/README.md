# ReAlgo — финальная презентация

Автономный HTML-дек на 19 слайдов для 10-минутного онлайн-выступления.
Сценарий занимает около 8:50 и оставляет запас на переключения и финальную паузу.

Дек — четвёртое приложение монорепозитория (рядом с `apps/web`, `apps/extension`
и `services/api`) и деплоится отдельным nginx-контейнером `presentation`.
Публично он доступен на **`https://realgo.dev/presentation/`**: Caddy снимает
префикс `/presentation` (`handle_path`) и проксирует запрос в контейнер, а
бесхитростный `/presentation` редиректится на слэш-вариант — без этого
относительные пути (`assets/…`, `vendor/…`) разрешались бы от корня сайта.

Почему отдельный контейнер, а не `apps/web/public/`: дек весит ~21 МБ (из них
11 МБ — одна glTF-модель) и меняется в своём ритме. В `public/` он попадал бы в
каждый слой образа `web` и в каждый его деплой, а собственные заголовки
кэширования (медиа на неделю, код — никогда) пришлось бы подгонять под общую
политику Next.

## Запуск

В составе стека (так же, как это работает в проде):

```bash
docker compose up -d --build presentation caddy
```

Дек открывается на `http://localhost:8080/presentation/` — порт задаёт
`API_PORT` (по умолчанию `8080`) в корневом `docker-compose.yml`.

Только контейнер презентации, без Caddy:

```bash
docker build -t realgo-presentation apps/presentation
docker run --rm -p 8080:80 realgo-presentation
```

Открывать в актуальном Chrome и включать полный экран: Chrome нужен для
переходов Magic Move на базе View Transitions API, а для трёхмерного MacBook —
включённый WebGL.

### Live development

Для правки слайдов без пересборки образа — dev-сервер с автоперезагрузкой:

```bash
node apps/presentation/dev-server.mjs
```

Открыть `http://127.0.0.1:8080`. После изменения HTML, CSS, JavaScript или
ассетов вкладка перезагрузится примерно за секунду. Live reload меняет только
локальное отображение — история фиксируется обычными `git commit` / `git push`.

Открыть `index.html` файлом тоже можно, но локальный сервер надёжнее
воспроизводит видео.

## Управление

- `←` / `→` — предыдущий или следующий слайд
- `Space` — следующий слайд
- `N` — показать или скрыть заметки спикера
- `F` — полноэкранный режим
- `R` — сбросить таймер выступления
- `?` — подсказка по управлению

Номер слайда можно открыть через hash: `http://127.0.0.1:8080/#7`.

## Состав

- `index.html` — содержание презентации
- `apple.css` — минималистичная Keynote-визуальная система и анимации
- `deck.js` — навигация, таймер и заметки спикера
- `macbook-3d.js` — Three.js-сцена, screen-aware камера, кинематографичный свет и процедурная текстура дисплея
- `product-ui-source.tsx` — сценарии живой демонстрации на production-компонентах `PopupApp` и `AssistantApp`
- `assets/product-ui.js` — автономная браузерная сборка настоящего интерфейса расширения
- `assets/models/macbook-pro-m3-16.glb` — локальная модель MacBook Pro
- `vendor/three/` — локальная сборка Three.js без CDN
- `archive/v1/` — предыдущая 12-слайдовая версия
- `qa/apple/` — контрольные кадры новой версии в разрешении 1920×1080
- `qa/product-capture/` — воспроизводимый стенд записи на компонентах из актуального репозитория ReAlgo

Четыре продуктовых сценария работают без видео: актуальные `PopupApp` и `AssistantApp` собраны прямо из репозитория расширения и монтируются как живой DOM поверх детерминированной сцены задачи. Сначала окно повторяет перспективу наклонённого дисплея, затем отделяется от него, выходит в фокус и приглушает фон. На screen texture добавлена слабая RGB-субпиксельная сетка, проявляющаяся только в близких планах. Слайды с рыночными данными содержат кликабельные источники мелким шрифтом.

MacBook занимает весь экран без рамки слайда. Камера плавно приближается к нужной зоне интерфейса и продолжает движение через все четыре продуктовых слайда; её ракурс вычисляется по реальной плоскости наклонённого экрана, поэтому close-up остаётся оптически выровненным с дисплеем. Движение за курсором отключено. Устройство проявляется из темноты под узким верхним и холодным контурным светом, а точная геометрия гравировки клавиатуры светится белым.

Переходы связывают объекты между соседними слайдами: числа преобразуются в следующие метрики, схема цикла превращается в полноэкранный ноутбук, продуктовый экран перестраивается в AI-интерфейс, карточки переходят в Pattern Atlas, а цены — одна в другую.

На слайдах 2–4 крупная метрика закреплена в одной точке и сохраняет одинаковый кегль. При смене слайда значение за 1,28 секунды численно проходит промежуточные значения: дробная часть с запятой растворяется перед целым числом, а знак процента проявляется через мягкую маску. Верхняя подпись, тезис, пояснение и источники сменяются отдельными переходами.

Модель MacBook создана Maroi Mister Let Me Think Official 3D Studio и распространяется по CC BY 4.0. Атрибуция и ссылка на исходную страницу Sketchfab указаны непосредственно на продуктовых слайдах.
