В задаче про дубликаты мы записывали на листок каждое число, которое уже видели. Теперь рядом с ним будем отмечать, сколько раз оно нам встретилось. Такой приём называется подсчётом частот (Frequency Counting).

## Постановка задачи

Дана строка `"ананас"`. Найдём первую букву, которая встречается в ней ровно один раз, и вернём её индекс. Индексы считаем с нуля. Если в строке каждая буква повторяется или строка пустая, вернём `-1`.

## Способ решения

Берём букву и проверяем, встречается ли она где-нибудь ещё в слове. Для этого смотрим и слева, и справа от неё. У первой `а` есть пара справа, на позиции `2`. А у последней `а` справа осталась только `с`. Если смотреть только вперёд, мы бы решили, что эта `а` встретилась один раз, хотя слева есть ещё две.

Так можно проверить каждую букву, но для этого придётся раз за разом просматривать одну и ту же строку. В худшем случае такой поиск займёт `O(n²)` по времени.

Давайте снова возьмём наш листок. Видим первую `а` и пишем рядом с ней `1`. Следом идёт `н`, для неё тоже запишем `1`. Доходим до второй `а`. Она у нас уже записана, поэтому исправим рядом с ней `1` на `2`.

Когда дочитаем слово до конца, на листке останутся три записи.

| Буква | Сколько раз встретилась |
|---|---:|
| `а` | 3 |
| `н` | 2 |
| `с` | 1 |

Теперь пройдём по слову ещё раз, слева направо. Каждый раз, когда встречаем `а` или `н`, идём дальше: по нашим записям обе буквы повторяются. На позиции `5` стоит `с`. Рядом с ней на листке записана `1`, значит, мы нашли первую букву без пары. Возвращаем `5`.

### Пример решения на Python

В Python наши записи удобно хранить в словаре. Назовём его `counts`. Если мы впервые видим букву, заведём для неё счётчик со значением `0`. Затем прибавим `1` за букву, которую сейчас читаем.

```python
def first_unique_char(text: str) -> int:
    counts = {}

    for char in text:
        if char not in counts:
            counts[char] = 0
        counts[char] += 1

    for index, char in enumerate(text):
        if counts[char] == 1:
            return index

    return -1
```

Во втором цикле `enumerate(text)` даёт нам сразу и индекс, и букву. Как только находим букву со счётчиком `1`, возвращаем её индекс. Если дошли до конца, возвращаем `-1`.

Мы проходим по строке не больше двух раз. Проверка и обновление счётчика в словаре занимают в среднем `O(1)`, поэтому для строки длиной `n` всё решение занимает в среднем `O(n)` времени. В словаре храним по одной записи на каждую разную букву.

Тот же подсчёт пригодится, если нас попросят найти самую частую букву. В слове `"ананас"` это `а`: она встретилась три раза.
