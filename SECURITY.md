# Политика безопасности

## Поддерживаемая версия

Исправления безопасности выпускаются для текущей версии ветки `main`.

## Как сообщить об уязвимости

Не публикуйте сведения об уязвимости в обычном issue. Используйте приватный
security advisory в разделе **Security → Advisories → New draft security
advisory** репозитория.

В сообщении укажите затронутый компонент, шаги воспроизведения, возможное
влияние и безопасный способ проверить исправление. Не прикладывайте реальные
токены, пароли, cookies, персональные данные или другие секреты.
